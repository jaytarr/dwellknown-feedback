# Try DwellKnown on Android

The private DwellKnown Android Preview uses shared test data. Use sample details and leave real home, product, warranty, receipt, photo, document, password, and payment information out of the test.

## Install and sign in

1. Open the private Android Preview link supplied by the DwellKnown team. If
   the link has expired, ask the team for the current build.
2. Download and install the build. If Android asks you to allow installations
   from your browser, allow it for this install only.
3. Open **DwellKnown**.
4. Under **Tester access**, choose **Free homeowner** and select **Continue**.
   If the project team assigned you another testing profile, use that one.

## Complete the first journey

1. Open **Records**, then select **Add a record**.
2. Choose **Purchased item**, then **Continue**.
3. Enter `Tester record` followed by the current date and time as the record
   name, choose **Small appliance**, then select **Continue**.
4. Choose **Personal item / moves with me**, leave the optional fields empty,
   then select **Continue**.
5. Review the details and select **Save record**.
6. Confirm the new record appears in **Records**.
7. Fully close the app, reopen it, and confirm the same record is still in
   **Records**.

The visible success result is the same named record after the app has been
closed and reopened.

## Send feedback

In the app, open **Account** → **Support** → **Send feedback**, or open
[Send DwellKnown feedback](https://github.com/jaytarr/dwellknown-feedback/issues/new?template=tester-feedback.yml).

Tell us approximately when the problem occurred, what you tried, and what you
saw. Reports are public and require a GitHub sign-in. Do not include
credentials, sign-in codes, home addresses, record contents, photos, documents,
receipts, or payment information. The project team already knows which build
was supplied and will correlate that information internally.

# Essayer DwellKnown sur Android

La version Preview privée de DwellKnown pour Android utilise des données de test
partagées. Utilisez des exemples et laissez de côté tout renseignement réel sur
un domicile, un produit ou une garantie, ainsi que les reçus, photos, documents,
mots de passe et renseignements de paiement.

## Installer l’application et ouvrir une session

1. Ouvrez le lien privé pour Android fourni par l’équipe DwellKnown. Si le lien
   a expiré, demandez à l’équipe la version actuelle.
2. Téléchargez et installez l’application. Si Android vous demande d’autoriser
   l’installation à partir du navigateur, accordez cette autorisation pour
   cette installation seulement.
3. Ouvrez **DwellKnown**.
4. Dans **Accès pour les testeurs**, choisissez **Propriétaire — offre gratuite**,
   puis **Continuer**. Si l’équipe vous a attribué un autre profil de test,
   utilisez celui-ci.

## Effectuer le premier parcours

1. Ouvrez **Dossiers**, puis sélectionnez **Ajouter un dossier**.
2. Choisissez **Article acheté**, puis **Continuer**.
3. Entrez `Dossier test` suivi de la date et de l’heure comme nom du dossier,
   choisissez **Petit électroménager**, puis sélectionnez **Continuer**.
4. Choisissez **Article personnel que j’emporte avec moi**, laissez les champs
   facultatifs vides, puis sélectionnez **Continuer**.
5. Vérifiez les renseignements et sélectionnez **Enregistrer le dossier**.
6. Confirmez que le nouveau dossier apparaît dans **Dossiers**.
7. Fermez complètement l’application, rouvrez l’application et confirmez que le
   même dossier apparaît toujours dans **Dossiers**.

Le résultat visible attendu est le même dossier nommé après la fermeture et la
réouverture de l’application.

## Envoyer des commentaires

Dans l’application, ouvrez **Compte** → **Soutien** → **Envoyer des
commentaires**, ou ouvrez [Envoyer des commentaires sur DwellKnown](https://github.com/jaytarr/dwellknown-feedback/issues/new?template=tester-feedback.yml).

Indiquez approximativement l’heure du problème, ce que vous tentiez de faire et
ce que vous avez vu. Les rapports sont publics et nécessitent une ouverture de
session GitHub. N’incluez aucun identifiant, code d’ouverture de session,
adresse de domicile, contenu de dossier, photo, document, reçu ni renseignement
de paiement. L’équipe du projet connaît déjà la version qui vous a été fournie
et établira le lien à l’interne.
