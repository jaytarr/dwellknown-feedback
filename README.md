# DwellKnown feedback / Commentaires sur DwellKnown

This public repository provides the [Android testing guide](TRY-DWELLKNOWN.md)
and collects feedback from DwellKnown early testers. Select **New issue**, then
choose **DwellKnown tester feedback**.

Do not include passwords, sign-in codes, home addresses, warranty or record
contents, photos, documents, receipts, or payment information.

---

Ce dépôt public fournit le [guide de test Android](TRY-DWELLKNOWN.md) et
recueille les commentaires des premiers testeurs de DwellKnown. Sélectionnez
**New issue**, puis **DwellKnown tester feedback**.

N’incluez pas de mot de passe, de code d’ouverture de session, d’adresse de
domicile, de contenu de garantie ou de dossier, de photo, de document, de reçu
ni de renseignement de paiement.
