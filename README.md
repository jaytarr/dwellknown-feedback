# WarrantyApp feedback / Commentaires sur WarrantyApp

This public repository collects feedback from WarrantyApp early testers. Select
**New issue**, then choose **WarrantyApp tester feedback**.

Do not include passwords, sign-in codes, home addresses, warranty or record
contents, photos, documents, receipts, or payment information.

---

Ce dépôt public recueille les commentaires des premiers testeurs de
WarrantyApp. Sélectionnez **New issue**, puis **WarrantyApp tester feedback**.

N’incluez pas de mot de passe, de code d’ouverture de session, d’adresse de
domicile, de contenu de garantie ou de dossier, de photo, de document, de reçu
ni de renseignement de paiement.
